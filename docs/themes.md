# Themes

## Dark Theme (default)

- Background: `#0d1117`
- Foreground: `#c0caf4`
- Accent: `#ffcc66`
- Success: `#a6e3a1`
- Warning: `#f9e2af`
- Error: `#f38ba8`
- Info: `#89b4fa`

## Light Theme

- Background: `#faf0eb`
- Foreground: `#4c4f69`
- Accent: `#d20f34`

## Custom Theme

Override `Theme` object or use `renderer.setTheme(theme)` with custom colors.

## High Contrast Theme

Use bright colors: `whiteBright` on `bgBlack`, with cyan accent.
